# Relasto – Real Estate Platform

**Relasto** is a full-stack real estate platform that connects property buyers with registered agents through a modern marketplace experience.

##  Features

*  User Registration & JWT Authentication
*  Buyer, Agent & Admin Roles
*  Property Listings & Details
*  Property Search & Filtering
*  Location-Based Property Search
*  Agent Profiles & Search
*  Property Visit Booking
*  Agent Reviews & Ratings
*  Property Image Management
*  Admin Property & User Management
*  RESTful API Integration

##  Tech Stack

* **Frontend:** React.js, JavaScript, Tailwind CSS
* **Backend:** Python, Django, Django REST Framework
* **Authentication:** JWT / Simple JWT
* **Database:** PostgreSQL
* **API:** REST API
* **Tools:** Git, GitHub, Postman

##  Project Setup

### Backend

```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r Reqiurement(virtual_env).txt
python manage.py migrate
python manage.py runserver
```

### Frontend

```bash
cd frontend
npm install
npm start
```

The backend runs on:

```text
http://127.0.0.1:8000/
```

## Application Flow

```text
User
```
